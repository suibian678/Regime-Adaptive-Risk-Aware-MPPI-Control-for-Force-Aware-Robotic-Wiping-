- [x] Title, author, independent affiliation, corresponding email, abstract,
  and six keywords are present.
- [x] Separate five-item Highlights file; each bullet is within 85 characters.

  through LaTeX/vector source.
- [x] Numbered references and complete bibliography source are included.
- [x] CRediT, funding, competing-interest, data/code, and generative-AI
  declarations are present.
- [x] Cover letter drafted for the journal's scope.
- [x] Public Git repository URL and archival DOI (10.5281/zenodo.22929983) inserted.
- [ ] Re-run the final PDF, citation, manifest, and plagiarism checks after the
  repository and archive identifiers are inserted.
- [ ] Submit only to RAS; do not submit the OJ-CS version concurrently.
